# CSN4214: Data Communications & Networking

## Course Description
This repository contains laboratory work and simulations for the Data Communications and Networking course. It covers both theoretical networking models and practical device configuration.

## Key Learning Areas
- **Network Topologies**: Designing and implementing star, bus, and mesh networks.
- **Protocol Configuration**: Setting up DHCP, DNS, and HTTP services.
- **IP Addressing**: Hands-on practice with subnetting and static/dynamic addressing.

## Laboratory Tools
- **Cisco Packet Tracer**: Primary tool for simulating complex network environments (`.pkt` files included).
